Portfolio Template 🌐

A modern, responsive, and accessible portfolio website template built with HTML, CSS, and Vanilla JavaScript.
Designed to showcase projects, skills, and personal information in a clean and professional way.

🔗 Live Demo: https://laurafonsecadesign.github.io/final-project-portfolio-template-2025/

✨ Features

Fully responsive layout (mobile, tablet, desktop)

Orientation-friendly design (portrait & landscape)

Semantic HTML5 structure

Accessible navigation and interactions

Smooth CSS animations with prefers-reduced-motion support

Clean and scalable CSS architecture

Performance-optimized assets

SEO and social media metadata included

🛠 Tech Stack

HTML5 – semantic markup

CSS3 – modern layout techniques (Flexbox / Grid)

Vanilla JavaScript – no frameworks

GitHub Pages – deployment

Prettier & ESLint – code formatting and linting

🚀 Getting Started

1. Clone the repository
   git clone https://github.com/your-username/portfolio-template.git

2. Open locally

You can open index.html directly in your browser
or use a local server (recommended):

npx serve

🌍 Deployment

This project is deployed using GitHub Pages.

To deploy:

Push your code to the main branch

Go to Settings → Pages

Select:

Source: main

Folder: /root

Save and wait for the live URL

📱 Responsive Design

The layout adapts to:

Mobile (320px+)

Tablet (768px+)

Desktop (1024px+)

Orientation changes (portrait / landscape)

No horizontal scrolling is introduced at any breakpoint.
